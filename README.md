# 模型車主動懸吊控制器 韌體更新檔

OpenActiveSuspension(ESP32-C3 SuperMini)的韌體發布專案. 這裡只放編譯好的韌體檔,不放原始碼.

## 怎麼更新

1. 控制器連上家用 WiFi(熱點模式沒有網路).
2. 先在網頁按「儲存」,把設定存好(更新會重新開機,沒存的變更會不見).
3. 網頁「系統 → 韌體更新 → 檢查更新」. 網站上有比較新的版本,會列出版本與修改說明.
4. 按兩下「更新」. 板子自己下載,檔案大小與檢查碼都對了才會安裝,然後重新開機.
5. **重新開機後保持網頁開著**:網頁會自動確認新韌體. 1 分鐘內沒有網頁連上,板子會自動退回舊版.

更新期間舵機會先收回中位,請勿斷電.

## 檔案

| 檔案 | 用途 |
|---|---|
| manifest.json | 最新版本資訊(板子讀這個) |
| CHANGELOG.md | 每一版修改了什麼 |
| firmware/ | 最近幾天的韌體檔;更早的版本在 Releases |

每天只留當天最新一版,當天的修改都合併在那一版的說明裡.
